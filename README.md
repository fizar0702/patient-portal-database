# Patient Chart Portal Database

## Project Overview
A group database project developed for a Database Systems course. The project uses SQL to create and manage a relational database for patient medical information.

## Technologies
- SQL
- MySQL
- Relational Database Design
- Primary and Foreign Keys
- Data Integrity Constraints

## Features
- Patient and doctor information management
- Appointment tracking
- Medical records and diagnoses
- Prescription management
- User accounts and audit logs

## Project Files
- `PatientPortal_Project.sql` — Main database project
- `Backup_PatientPortal.sql` — Backup SQL script

## How to Run
1. Open MySQL Workbench.
2. Connect to a local MySQL server.
3. Open `PatientPortal_Project.sql`.
4. Execute the script to create and populate the database.
